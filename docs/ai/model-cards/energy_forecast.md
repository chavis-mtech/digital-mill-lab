## Purpose
AI-E01: hourly plant electricity forecast conditional on planned processed FFB and running time.

## Input features
`ffb_processed_t`, `running_minutes`, `throughput_tph`, `hour_local`, `weekday_local`

## Training data
energy_consumption plant meter (process_stage_id NULL) joined with process_hourly.

## Synthetic-data assumptions
- Synthetic Demonstration Data from a fictional mill ('Demo Palm Mill A'); 120 days, one line; no company data.
- We generated the data ourselves, so the generator's drivers are fully observable; real plants have unmeasured drivers, sensor drift and labelling gaps - expect worse results on real data.
- Temporal split: train < 2026-10-15 00:00 Asia/Bangkok, test >= it. injected_events (ground truth) are used only for evaluation and for tuning thresholds on the training period.
- In production the hourly production plan would be an input; the API uses the last 7 days' hour-of-day profile.

## Evaluation method
Test MAE/RMSE (hourly and daily totals) vs a linear energy signature (kWh = a + b*FFB + c*running minutes) and seasonal-naive 24 h.

## Limitations
- Does not beat the linear energy-signature baseline on the test period (see metrics).
- Interval is the in-sample P90 residual (optimistic), not conformal.

## Known failure modes
- Idle running and leaks are not in the features by design (they are what the anomaly detector looks for).

## What is NOT claimed
- No real-plant accuracy. No calibrated probability. Anomalies are possible contributing factors, never proven causes; logistics flags are review requests, never accusations.
