## Purpose
AI-D04: 'unusual, needs review' flags for implausible net weights and excessive waits. Never an accusation.

## Input features
`net_kg`, `truck_type`, `wait_min`

## Training data
Weighbridge tickets per truck class; arrival-to-weigh-in waits.

## Synthetic-data assumptions
- Synthetic Demonstration Data from a fictional mill ('Demo Palm Mill A'); 120 days, one line; no company data.
- We generated the data ourselves, so the generator's drivers are fully observable; real plants have unmeasured drivers, sensor drift and labelling gaps - expect worse results on real data.
- Temporal split: train < 2026-10-15 00:00 Asia/Bangkok, test >= it. injected_events (ground truth) are used only for evaluation and for tuning thresholds on the training period.
- Injected weight outliers are 8-13% above the class maximum payload.

## Evaluation method
Weight flags vs injected implausible-weight labels (all in the training period); wait flags vs the queue-episode labels.

## Limitations
- Test-period weight recall is undefined (no test labels); only false flags are measured.
- Per-truck wait flags (> training P99) are review items only and raise no alerts; alerts come from the sustained queue rule (>= k trucks past P99 within 3 h), whose k was set by a false-alarm budget because the training period has no queue-episode label.

## Known failure modes
- A truck-class mistake on the ticket produces a weight flag (which is exactly what review should catch).

## What is NOT claimed
- No real-plant accuracy. No calibrated probability. Anomalies are possible contributing factors, never proven causes; logistics flags are review requests, never accusations.
